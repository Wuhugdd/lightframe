# LightFrame 硬件指南

## 硬件清单

| 部件 | 规格 | 说明 |
|------|------|------|
| 主控 | ESP32-S3 开发板 | 推荐 ESP32-S3-DevKitC-1 |
| LED 点阵 | 8×32 WS2812B | 共 256 颗灯珠 |
| 麦克风 | 模拟麦克风模块 | 连接到 ADC 引脚 |
| 光敏电阻 | 任意型号 | 用于自动亮度 |
| 按键 | 3 个轻触按键 | |
| 蜂鸣器 | 有源蜂鸣器 | 可选，按键反馈 |
| 电源 | USB-C 5V/2A | 全亮电流约 1-2A |

## 接线图

| ESP32-S3 引脚 | 部件 |
|----------------|------|
| GPIO5 | WS2812 DIN |
| GPIO32 | 麦克风输出 |
| GPIO33 | 光敏电阻 |
| GPIO25 | 按键 1（模式切换） |
| GPIO26 | 按键 2（亮度调节） |
| GPIO27 | 按键 3（确认） |
| GPIO22 | 蜂鸣器 |
| 5V | LED 点阵电源 |
| GND | 共地 |

## 注意事项

1. **电源功率**：256 颗 WS2812 全亮最大电流约 1.5A，请确保电源能提供足够功率
2. **电平转换**：大部分 WS2812 模块可以直接接受 3.3V 电平，部分需要加电平转换
3. **光敏电阻安装**：尽量放在能感应环境光但不被 LED 本身照射的位置
