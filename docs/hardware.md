# LightFrame 硬件指南

## 一、功耗计算

### WS2812B 灯珠参数

| 参数 | 数值 |
|------|------|
| 灯珠数量 | 8×32 = 256 颗 |
| 单颗全亮电流 | 60mA（R/G/B 各 20mA） |
| 工作电压 | 5V |

### 电流估算

| 场景 | 计算方式 | 电流 | 功率 |
|------|----------|------|------|
| 理论峰值（全白全亮） | 256 × 60mA | **15.36A** | 76.8W |
| 彩色图案，亮度 30% | 256 × 60mA × 30% | **4.6A** | 23W |
| 时钟/频谱模式，亮度 20% | 256 × 60mA × 20% | **3.1A** | 15.4W |
| 少量像素亮，亮度 10% | 256 × 60mA × 10% | **1.5A** | 7.7W |
| ESP32-S3（WiFi 活跃） | — | **0.24A** | 1.2W |
| **实际典型总功耗** | 时钟/频谱模式 + ESP32 | **≈ 1.8A** | **≈ 9W** |

> **结论**：日常使用建议将 FastLED 全局亮度限制在 20%~30%，既保护眼睛，也大幅降低功耗和发热。

### 电源选型

**USB 供电（推荐，桌面使用）**

- 最低要求：5V 2A（亮度限制在 20% 以内）
- 推荐规格：5V 3A USB-C 电源适配器
- 注意：灯板 5V 电源线要足够粗（≥22AWG），长线压降会导致颜色偏差

**电池供电（便携/无线使用）**

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 电池类型 | 18650 锂电池 × 2（并联）或软包锂电 | 3.7V 标称电压 |
| 容量 | 4000~6000mAh | 续航约 2~4 小时（典型使用） |
| 充放电芯片 | IP5306 或 TP4056 + MT3608 | IP5306 集成升压+充电+电量指示 |
| 升压模块 | 3.7V → 5V，输出电流 ≥ 3A | MT3608 或 XL6009 |
| 电量检测 | ADC 读取分压后的电池电压 | 满电 4.2V，截止 3.0V |

**电池电量估算公式（ADC 读取）**

```
电池电压 = ADC读值 / 4095 × 3.3V × 分压系数
分压系数 = (R1 + R2) / R2   （R1=100kΩ, R2=100kΩ → 系数=2）

电量百分比（近似）：
4.2V → 100%
3.9V → 75%
3.7V → 50%
3.5V → 25%
3.0V → 0%（截止，不可再放电）
```

## 三、引脚分配

| ESP32-S3 引脚 | 连接部件 | 说明 |
|----------------|----------|------|
| GPIO 5 | WS2812 DIN（串 330Ω） | LED 数据线 |
| GPIO 32 | 麦克风模块 OUT | ADC1 通道 |
| GPIO 33 | 光敏电阻分压中点 | ADC1 通道 |
| GPIO 34 | 电池电压分压中点 | ADC1 通道，仅输入 |
| GPIO 25 | 按键 1（模式切换） | 内部上拉，低电平触发 |
| GPIO 26 | 按键 2（亮度调节） | 内部上拉，低电平触发 |
| GPIO 27 | 按键 3（确认/返回） | 内部上拉，低电平触发 |
| GPIO 22 | 有源蜂鸣器 | 高电平触发 |
| 5V | 灯板 VCC + 充电模块输出 | 主电源 |
| GND | 所有模块共地 | — |

> ESP32-S3 的 GPIO 34/35/36/39 仅支持输入，不能输出，适合做 ADC 检测。

## 五、电路注意事项

1. **WS2812 数据线**：串联 330Ω 电阻，防止信号反射和 ESD 损坏
2. **灯板滤波电容**：在灯板电源正负极之间并联 1000μF 电解电容，防止上电瞬间冲击损坏第一颗灯珠
3. **电源分离**：灯板 5V 和 ESP32 3.3V 分开走线，共地即可，避免灯板大电流干扰 ESP32
4. **电池保护**：IP5306 内置过充/过放/短路保护；若用 TP4056 方案，需额外加保护板
5. **光敏传感器位置**：安装在不被灯板直接照射的位置（如背面或侧面），否则自动调光会失效
6. **ADC 精度**：ESP32 的 ADC 非线性较严重，电池电量检测建议多次采样取平均值，并做两点校准
