## ✨ 它为什么好看又好玩

> 放在桌面，既是时钟，也是音乐氛围灯，更是程序员的浪漫桌搭。

- **🕒 精准时钟** - 支持多种时钟样式，数字清晰醒目
- **🎵 实时频谱** - 麦克风采集音乐，FFT 计算瀑布频谱，随音乐跳动，氛围感拉满
- **🌈 多彩效果** - 彩虹渐变、单色主题、呼吸灯效，随心切换
- **🌓 自动调光** - 光敏传感器检测环境光，自动调节亮度，深夜自动关灯
- **🔧 小白友好** - Captive Portal 一键配网，网页可视化配置，不用改代码
- **🔄 多模式切换** - 按键短按切换模式，满足不同场景需求
- **🔌 可扩展** - JSON 驱动模式系统，自定义内容，写个 JSON 就能加新模式
- **☁️ 前后端分离** - 复杂计算放后端，设备只做显示和实时处理，省电又流畅

## 🧩 整体架构

我们采用**前后端分离**架构，让专业的东西放专业的地方：

```
┌─────────────────────────────────────────────────────────────┐
│                     浏览器 / 用户手机                          │
│  ┌─────────────┐    HTTP    ┌─────────────┐                  │
│  │ 网页配置界面 │ ←=======→ │ FastAPI 后端 │                  │
│  └─────────────┘            └─────────────┘                  │
└─────────────────────────────────────────────────────────────┘
                              ↑
                              │ HTTP
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                     ESP32-S3 (设备端)                         │
│  ┌─────────────┐ ┌─────────────┐ ┌─────────────┐            │
│  │ WS2812 驱动 │ │ 麦克风 FFT  │ │ 光敏自动调光 │            │
│  └─────────────┘ └─────────────┘ └─────────────┘            │
│  ┌─────────────┐ ┌─────────────┐ ┌─────────────┐            │
│  │ 按键处理     │ │ Captive Portal配网 │ │ NVS 存储       │            │
│  └─────────────┘ └─────────────┘ └─────────────┘            │
└─────────────────────────────────────────────────────────────┘
```

### 为什么这么设计？

| 做 法 | ESP32 直接处理一切 | LightFrame 前后端分离 |
|-------|-------------------|----------------------|
| 内存占用 | 大，要解析 JSON、渲染文字，容易爆内存 | 小，只存一帧 RGB 数据 |
| 耗电 | WiFi 长时间连接，CPU 高负载 | 下载完就休眠，省电 |
| 扩展性 | 加新功能要重刷固件 | 改后端配置立刻生效 |
| 开发体验 | 改一点就要编译刷写 | 后端改完刷新网页就好 |

## 🚀 快速开始

### 1. 硬件组装

按照接线图连接各个模块，具体参考 [硬件指南](docs/hardware.md)。

### 2. 编译刷入固件

```bash
cd firmware
pio run --target upload
```

### 3. 部署后端

```bash
cd backend
pip install -r requirements.txt
cp .env.example .env
# 填写你的天气 API Key（可选）
python -m uvicorn api.index:app --host 0.0.0.0 --port 8080
```

### 4. 开始配置

1. 设备开机，如果你是第一次使用，手机连接 `LightFrame-XXXX` AP
2. 自动弹出配网页，输入你的 WiFi 名称密码和后端地址
3. 保存后设备自动重启连接
4. 打开后端网页配置，选择你喜欢的模式和参数
5. 完成！享受你的桌面光帧吧！

## 🎨 自定义新模式

LightFrame 使用 JSON 驱动的模式系统，添加新模式**不需要改核心代码**：

```json
{
  "mode_id": "MY_CUSTOM",
  "display_name": "我的自定义模式",
  "cacheable": false,
  "content": {
    "type": "static",
    "text": "Hello World!"
  },
  "layout": {
    "color": "#FF00FF",
    "align": "center"
  }
}
```

把文件放到 `backend/modes/custom/`，重启后端就好了！
